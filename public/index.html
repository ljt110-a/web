欢迎来到我的空间

这是一个真正跑得起来的全栈起始模板：暗色主题与玻璃拟态留在前端，账号、密码、登录状态和访问计数全部交给后端接口与 MySQL 保存。想改配色，改 assets/css/style.css 顶部的变量即可。

这一版由三层组成

🎨

前端页面

public/ 目录下的静态页面，只负责展示与交互；所有数据都通过 fetch 调 /api/* 获取，不再存在浏览器里。

🖥️

后端接口

PHP 写的注册、登录、退出与后台接口；密码用 bcrypt 加盐哈希保存，登录状态靠服务端会话表校验。

🗄️

MySQL 数据库

users / sessions / visits 三张表，全部用预处理参数写入；换电脑、换浏览器看到的都是同一份数据。
